# DJ Fly Visual System

DJ Fly is designed as a living visual identity rather than a single image.

## Core motifs

- neon green club light
- black DJ hardware
- oversized headphones
- sunglasses
- gold chain and FLY pendant
- the FLY mark repeated across stage hardware
- dense crowd silhouettes
- haze, lasers, reflections, and motion

## Preview wall

The repository uses the `assets/` directory as a growing visual board. New posters, stage concepts, alternate portraits, close-ups, and performance frames can be added without changing the project structure.

The README intentionally treats visuals as part of the project interface. Keep preview images large, cinematic, and immediately recognizable as DJ Fly.
