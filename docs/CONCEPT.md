# DJ Fly concept

DJ Fly is a fictional nightclub character: a fly who somehow became the resident DJ.

The project deliberately treats the character like a tiny entertainment system rather than a conventional mascot. The fly has a stage, decks, a visual language, performance states, and an expanding collection of experiments.

## Performance loop

```text
ENTER CLUB
    ↓
LOCK TO BEAT
    ↓
BUILD ENERGY
    ↓
DROP
    ↓
LIGHTS / CROWD / FLY
    ↓
REPEAT
```

## Visual direction

The reference look is a high-energy neon club: deep blacks, electric green lighting, chrome DJ hardware, oversized headphones, sunglasses, gold details, and a recognizable FLY mark.

## Why the repository exists

The code is intentionally small. It provides a technical shell for creative work: generating states, driving visuals, prototyping interactions, and giving future DJ Fly experiments a common home.
