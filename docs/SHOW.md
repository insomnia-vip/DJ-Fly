# DJ Fly show system

A conceptual live-show layout for future visual prototypes.

| Layer | Role |
|---|---|
| FLY | main character and visual anchor |
| DECKS | beat and interaction state |
| LIGHTS | energy-driven visual intensity |
| CROWD | reactive background animation |
| BOOTH | persistent stage environment |
| SIGNAL | events emitted by the performance engine |

## Example states

- `INTRO` — empty booth, low energy
- `WARMUP` — steady beat and movement
- `DROP` — maximum visual pulse
- `CHAOS` — rapid transitions and crowd response
- `OUTRO` — lights fade, DJ Fly remains on deck
