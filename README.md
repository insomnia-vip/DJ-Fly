## The idea

DJ Fly is a fictional DJ built around one simple concept: **what happens when a fly gets behind the decks and refuses to leave?**

The repository is a home for the character, visual experiments, show concepts, generated media, and small creative prototypes that turn the DJ Fly idea into something people can actually explore.

## What's inside

```text
assets/      DJ Fly artwork, banners, posters, and media
concepts/    stage ideas, show concepts, and visual experiments
audio/       sound experiments and DJ Fly references
docs/        project notes and world-building
web/         small interactive DJ Fly experiments
```

## DJ Fly

The character is simple:

**FLY** on the cap.

**FLY** on the decks.

**FLY** in the booth.

Somehow the whole room starts moving.

## Experiments

This repository intentionally mixes polished material with weird prototypes. Some things are serious production experiments. Some are visual jokes. Some probably should not work at all.

That is part of the point.

## Visual identity

The primary DJ Fly aesthetic is built around:

- neon green club lighting
- black hardware and streetwear
- oversized headphones
- sunglasses
- gold chain details
- loud nightclub energy
- the FLY mark as the central visual element
